# Changelog

## 1.0.4

- ChatGPT: ApeScope puts the prepared prompt into your ChatGPT tab and you send it yourself with Enter. The *Send automatically* option is removed, ApeScope never sends messages for you.

## 1.0.3

- Narrower permissions: ApeScope only gets access to the sites and data services it uses. Access to all websites is now optional and only needed for the website check (contract address on the project website) and a custom Solana RPC; it is granted on the extension's settings page with *Allow website checks*.

## 1.0.2

- Firefox: new add-on ID for the listing on Firefox Add-ons, minimum version Firefox 140 (Android 142), which the data collection declaration needs.

## 1.0.1

- *Check for updates* in Chrome, Edge and Brave now always looks for a newer GitHub release. Before, Chrome's own store check answered "checked recently" for unpacked installs and the release check was skipped.

## 1.0.0

First public release.

- Sidebar next to the fomo chart for Chrome and Firefox: docked left or right (the page moves aside), floating or collapsed.
- Risk checks grouped into red flags, warnings, good signs and info: liquidity, bump bots, contract flags, LP lock, sell simulation, rug report, organic score, look-alikes.
- Holders: top 10 without pools and bonding curves, bundlers, insiders, snipers, phishing wallets, bots, fresh wallets, wallet clusters, smart money and KOLs.
- Developer: tokens launched and migrated, position, funding wallet, X renames, reused logos.
- Project: website and GitHub with the contract address check, domain and account age, launchpad, trading and research links, creator fees with fee sharing recipients and claims.
- Socials: fomo theses and pump.fun callouts with the top callers by followers, X posts, activity from 5 minutes to 24 hours, chart markers.
- Live data every few seconds, buy and sell pressure, holder growth, watchlist with alerts.
- ChatGPT: full due diligence prompt or a trade setup with entry and exit scenarios, sent to your own ChatGPT tab.
- Updates from the settings: check GitHub releases, install from a dropped file.
